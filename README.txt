SK POLYMERS — PTFE & Teflon manufacturing website
=================================================

A static, multi-page website generated by a zero-dependency Node script (Node 18+).
No framework, no npm install. The generated HTML is committed, so Vercel serves plain
static files with no build step.

EDIT → BUILD → CHECK
  1. Edit source files in src/ (never the generated .html files in the repo root).
  2. node build.mjs              regenerate every page, sitemap.xml, robots.txt, vercel.json
  3. node scripts/validate.mjs   checks titles, canonicals, links, JSON-LD, sitemap, banned claims
  4. node scripts/serve.mjs      preview at http://localhost:4173/ (mimics Vercel routing)
  Commit the src/ changes AND the regenerated output together.

LAYOUT
  build.mjs                      the generator
  src/config.mjs                 SITE_URL (canonical domain), business facts, GA4 / Search Console IDs
  src/layout.mjs                 shared <head>, header, footer, enquiry form, page components
  src/seo.mjs                    JSON-LD structured data
  src/data/catalogue.mjs         product/service/article list (cards, footer, form options)
  src/data/ptfe.mjs              typical PTFE property + grade tables shared by all pages
  src/pages/**                   one module per page (path, title, description, body)
  static/css/style.css           design system (tokens at the top)
  static/js/style.js             interactions, enquiry form, analytics events
  static/fonts/                  self-hosted Inter, Space Grotesk, JetBrains Mono (SIL OFL)
  static/images/                 illustrations, photos, icons, social (OG) image
  scripts/make-images.mjs        regenerates icons + OG image (needs Chrome + Python Pillow)
  scripts/render-page.mjs        renders one page module for a quick check
  DEPLOYMENT.md                  Vercel, custom domain, Search Console, GA4, Business Profile

ADDING A PAGE
  Copy an existing module in src/pages (e.g. products/ptfe-sheets.mjs), change path/title/
  description/body, add it to src/data/catalogue.mjs if it should appear in menus, then build.
  Titles ≤ 60 characters, descriptions ~130–158, exactly one H1 (from pageHero).

CHANGING THE DOMAIN
  See DEPLOYMENT.md. In short: attach the domain in Vercel first, then set SITE_URL in
  src/config.mjs, run node build.mjs, commit and push. The build adds a 301 redirect from
  skpolymers.vercel.app to the new domain automatically.

THINGS THE OWNER MUST SUPPLY (nothing here is invented)
  - Full address: unit/gala number, locality and PIN code → src/config.mjs BUSINESS.address.
    LocalBusiness structured data switches on automatically once all three are filled.
  - Certifications, years in business, client numbers: removed until verified. Only add
    them back with evidence (certificate numbers, issuing body).
  - Testimonials: removed. Add only genuine, permissioned quotes.
  - Product size ranges marked "indicative" (sheet thickness, rod diameter): confirm or edit.
  - Better photographs: the four photos in static/images/photos are 171–261 px wide (except
    turling). Real in-house photos at ≥1200 px will improve trust and image search.
  - A business email on the company domain once purchased (currently a Gmail address).

ENQUIRY FORM
  The form validates input, then opens the visitor's email app with the enquiry filled in
  (mailto). Nothing is sent until the visitor presses Send; the on-page message says so and
  offers WhatsApp with the same text as a fallback. To receive submissions server-side later,
  POST the same fields to a form service in static/js/style.js (buildEnquiry()).
